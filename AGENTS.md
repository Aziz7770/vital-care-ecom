# Project rules

- Site visibility is controlled by `LANDING_ONLY` in `src/config/siteMode.ts`; keep both full-site and landing-only routes intact and keep the public sitemap aligned with the active routes. Why: the saved full website must remain restorable without undoing order security or tracking fixes.
- Any edge-function call that sends to TikTok's Events API must be invoked with `region: FunctionRegion.ApSoutheast1`. Why: Bangladesh visitors otherwise route to the India region, whose IPs TikTok rejects ("banned Country list").
- Meta tracking uses the Pixel in `index.html` (`__TRACK_OK` host gate: owner domain plus Lovable preview/published hosts, no base PageView, `autoConfig` off, `disablePushState`); every event goes through `fbqSafe`, which fires only on `META_BROWSER_SAFE_PATHS` with neutral fields. Purchase is sent once: server Purchase from `notify-order` is primary, and Checkout fires the browser Pixel Purchase only when the server copy was not accepted (`metaServerPurchaseAccepted`). The only server event is Purchase from `notify-order` (Pixel ID and token env name in `_shared/metaSafe.ts`, `event_id` = order ID for dedup, hosts via `isMetaTrackedSite`); `notify-form`/`meta-capi-event` stay off via `isLegacyMetaEnabled`. Google Tag Manager and `dataLayer` pushes are removed. Why: page addresses and product data can reveal medical details, and the site must not leak them to Meta.
