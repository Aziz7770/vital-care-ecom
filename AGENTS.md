# Project rules

- Site visibility is controlled by `LANDING_ONLY` in `src/config/siteMode.ts`; keep both full-site and landing-only routes intact and keep the public sitemap aligned with the active routes. Why: the saved full website must remain restorable without undoing order security or tracking fixes.
- Any edge-function call that sends to TikTok's Events API must be invoked with `region: FunctionRegion.ApSoutheast1`. Why: Bangladesh visitors otherwise route to the India region, whose IPs TikTok rejects ("banned Country list").
- Meta tracking uses the Pixel in `index.html` with a separate `__META_TRACK_OK` host gate mirrored by `isMetaTrackedSite` in server and browser event/customer guards; keep the TikTok gate independent. No base PageView, `autoConfig` off, `disablePushState`; every browser event goes through `fbqSafe` only on `META_BROWSER_SAFE_PATHS` with neutral fields. Purchase is sent once: server Purchase from `notify-order` is primary, and Checkout fires browser Purchase only when `metaServerPurchaseAccepted` is false. The only server event is Purchase from `notify-order` (credentials in `_shared/metaSafe.ts`, `event_id` = order ID); Telegram is sent before Meta, independently of its result. `notify-form`/`meta-capi-event` stay off via `isLegacyMetaEnabled`; GTM and `dataLayer` pushes stay removed. Why: separate host gates prevent accidental cross-provider changes and keep order delivery independent from ad tracking.
