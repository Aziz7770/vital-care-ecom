# Project rules

- Site visibility is controlled by `LANDING_ONLY` in `src/config/siteMode.ts`; keep both full-site and landing-only routes intact and keep the public sitemap aligned with the active routes. Why: the saved full website must remain restorable without undoing order security or tracking fixes.
- Any edge-function call that sends to TikTok's Events API must be invoked with `region: FunctionRegion.ApSoutheast1`. Why: Bangladesh visitors otherwise route to the India region, whose IPs TikTok rejects ("banned Country list").
- Meta tracking is browser-only through the Pixel in `index.html` (`__TRACK_OK` host gate: owner domain plus Lovable preview/published hosts, no base PageView, `autoConfig` off, `disablePushState`); every event goes through `fbqSafe`, which fires only on `META_BROWSER_SAFE_PATHS` with neutral fields. Identifier capture and the three server senders stay off via `isLegacyMetaEnabled`. Google Tag Manager and `dataLayer` pushes are removed. Why: page addresses and product data can reveal medical details, and the site must not leak them to Meta.
